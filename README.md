# Geometry Algorithms
 
Interactive geometry and mesh processing experiments
written in C++ and OpenGL.
 
## Current Features
- OBJ Loader
- Triangle Mesh Rendering
- Orbit Camera
- Bounding Box Fitting
- Stanford Bunny Rendering
- Face Normal Visualization
- Vertex Normal Visualization
