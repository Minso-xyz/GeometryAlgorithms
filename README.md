# Geometry Algorithms
 
Interactive geometry and mesh processing playground
written in C++ and OpenGL.
 
## Current Features
- OpenGL Viewer
- Orbit Camera
- Mesh Rendering
- OBJ Loader
- Stanford Bunny Rendering
